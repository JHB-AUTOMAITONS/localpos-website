Five QR codes a shop can put to work

Each of these takes a minute to make and costs only the print.

  • UPI at the counter

    Print a payment code with your UPI ID and payee name. The customer scans it in any UPI app and types the amount.

  • Wi-Fi for guests

    A cafe, salon or clinic can let visitors join the guest network by scanning, without spelling out the password.

  • Menu or catalogue link

    Point the code to your online menu, price list or product catalogue and place it on tables or the shop window.

  • Google review link

    Put your review link in a code near the billing counter so a happy customer can leave a rating before walking out.

  • Visiting card

    A contact code saves your name, phone and email to the phone book in one scan. Pair it with a logo from the logo maker.

  • Text on a label

    Store a short note, a batch reference or care instructions as plain text on a product sticker.

What to enter for each type of code

Link
A full web address, starting with https://. Shorter addresses make simpler codes that scan faster.
Text
Any short message. The phone shows the text as it is, with nothing to open.
Wi-Fi
The network name exactly as it appears on a phone, the password, and the security type: WPA/WPA2, WEP or none. Tick the hidden network box if your router does not broadcast its name.
Contact
Name, organisation, phone, email and website. These are saved as a vCard, the standard contact format that phones understand.
UPI payment
Your UPI ID and payee name, with an optional amount and note. The result is a standard upi://pay code that UPI apps can scan.

Static and dynamic QR codes: which one is this?

This QR code generator makes static codes. The link, text or UPI ID is stored inside the pattern itself. Nothing sits on a server in between, so there is no account to keep and nothing to renew.

A dynamic code works differently. It holds a short redirect address run by a service provider, and the provider can change where it leads and count the scans. That needs an account with the provider and the code depends on their service staying active.

The practical result: a static code cannot be edited after printing, and it has no tracking or scan counts. If your menu link or Wi-Fi password changes, make a new code and reprint. A code made here keeps working for as long as the thing it points to stays valid.

Keep the destination stable

Before printing a large batch, choose a web address you do not expect to change, such as a page on your own domain.

Error correction levels explained

Error correction lets a scanner read a code that is partly scratched or dirty. Higher levels add more squares, so the code becomes denser. The recovery figures are the approximate values from the QR standard.

LevelDamage it can absorbWhere it suits
LowAbout 7%Screens and clean indoor prints with long content
MediumAbout 15%Most everyday uses, a sensible default
QuartileAbout 25%Counter stands and labels that get handled
HighAbout 30%Stickers and outdoor prints that may wear

If the content is long, a lower level keeps the squares larger and easier to scan. If the content is short, a higher level costs very little.

From download to a print that scans

  1. 01

    Pick the file type

    Download SVG for a print shop, because it stays sharp at any size. Download PNG at 512, 1024 or 2048 px for documents, WhatsApp and web pages.

  2. 02

    Size it sensibly

    Keep the printed code at least about 2 cm wide for scanning from close range. Go larger for a counter stand or a poster that people scan from a distance.

  3. 03

    Protect the margin and contrast

    Leave the white border around the code clear of text and artwork. Print it black on white or on a very light surface, and avoid glossy lamination that reflects light.

  4. 04

    Test before the print run

    Scan the proof with two different phones. For a payment code, confirm the payee name the app shows. You can also check the file itself with the QR code scanner.

Will a QR code made here stop working after some time?

The code itself has no timer, because the content is stored in the pattern and not on a server. It works as long as what it points to stays valid. If the web page is removed, the UPI ID is closed or the Wi-Fi password changes, you need a new code.

Can I change the link after printing the code?

No. These are static codes, so the content cannot be changed once printed. Create a QR code with the new link and replace the old print.

How do I make a UPI QR code for my shop?

Choose UPI payment, enter your UPI ID exactly as your bank app shows it, and add the payee name. Leave the amount blank if customers pay different amounts. Scan the result with a UPI app and confirm the name before printing.

Why does my code look so dense?

More content means more squares. Long links, long text and a high error correction level all add density. Shorten the content or choose a lower level, and print the code larger.

Should I download PNG or SVG?

Use SVG for anything a printer will resize, such as a standee, a board or packaging. Use PNG for a bill footer, a document or a message. The 2048 px PNG is the safest choice for print if your software cannot open SVG.

Is this QR code maker the right tool for product labels?

It works for links and text on labels. For the numbers that a billing counter scans, a one-dimensional barcode is the usual choice. The barcode generator makes Code 128, EAN and UPC labels.
