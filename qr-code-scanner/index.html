QR Code Scanner: read a QR from an image

This QR code scanner reads a code from a photo or screenshot and shows you what is inside it. Choose, drop or paste the image, and the content appears with a button to copy it.

  • Decoded in your browser
  • Image never uploaded
  • Choose, drop or paste

QR code scanner from image

Add a picture that contains one QR code.

Choose an image that contains a QR code

Drag a picture here, paste a screenshot with Ctrl+V, or choose a file. JPG, PNG or WebP, up to 15 MB.

Your image is read on this device, in your browser. It is not uploaded or stored.

Result

The content of the QR code will appear here.

Privacy: your image stays on your device

The picture you choose is decoded inside your browser. It is never uploaded to LocalPOS or to anyone else, and the result is shown only on your screen.

That matters because a QR code can hold private details: a Wi-Fi password, a UPI ID, a phone number or a link to a personal document. The tool is free and needs no sign-up, so there is no account in which results could be stored.

Closing the tab clears it

Nothing is saved between visits. Copy the result before you leave the page if you need it later.

When scanning from an image is the only way

A phone camera cannot point at its own screen. These are the usual situations.

  • A code sent on WhatsApp or email

    A supplier sends a payment code or a customer sends a location link as a picture. Save the image and open it here.

  • A screenshot

    You captured a code from a website, an app or a video call and want to see what it contains before acting on it.

  • A code on a PDF invoice

    Take a screenshot of the part of the invoice that carries the code, then paste it straight into the tool.

  • Your own artwork before printing

    Check that the file you are sending to the printer really holds the right link or UPI ID. Codes from the QR code generator can be verified this way.

How to scan a QR from an image

  1. 01

    Add the picture

    Choose a file, drag and drop it on the box, or paste a copied image. JPG, PNG, WebP and other formats your browser can open are accepted, up to 15 MB.

  2. 02

    Read the result

    The decoded content appears with a label that says what it is: a link, plain text, Wi-Fi details, UPI payment details or a contact card.

  3. 03

    Copy or open

    Press Copy to put the content on your clipboard. For a link you also get an Open link button. Read the address first.

Reading the result by type

Link
The full web address is shown. Look at the domain name, the part just after https://, before opening it.
Plain text
The text is shown exactly as stored. It may be a note, a serial number or a coupon code.
Wi-Fi details
The network name, the security type and the password. You can type these into a laptop or another device that cannot scan.
UPI payment details
The UPI ID and payee name, plus the amount and note if the code carries them. This shows who would be paid.
Contact card
The name, phone, email and other fields saved in the card.

Troubleshooting: when the code is not read

ProblemLikely causeWhat to try
“Not an image” messageThe file is a PDF, a document or a damaged fileTake a screenshot of the code and use that instead
No readable QR code foundThe code is very small inside a large photoCrop closer so the code fills most of the picture
Blurred photoCamera shake or a forwarded, compressed imageAsk for the original file or retake the photo in good light
Faint or coloured codeLow contrast between the squares and the backgroundUse a clearer copy. Dark squares on a light background read well
Tilted or curved codePhotographed at a steep angle or on a bottleRetake the photo straight on, with the code lying flat

The tool reads one code per image. If a picture has several, crop to the one you need.

What this tool covers

Good for

  • Codes saved as pictures or screenshots
  • Seeing the content before you open or pay
  • Copying a Wi-Fi password or a long link to another device
  • Checking print files before a print run

Not built for

  • Live camera scanning. Use your phone’s camera app for that
  • Several codes in a single image
  • Product barcodes. Those go to the barcode scanner
  • Making payments. It only shows the details

Check before you open or pay

A QR code from an unknown source can lead to a fake website. Read the address and open it only if you recognise it. For a UPI code, verify that the payee name is the person or shop you mean to pay. Remember that scanning a code is for paying money. You do not need to scan anything or enter your UPI PIN to receive money.

Questions about reading QR codes from images

Still have a question?

Talk to our team
Is my image uploaded when I scan it?

No. The image is decoded in your browser on your own device. It is not sent to a server and it is not stored.

Can I scan with my camera on this page?

No. This page reads codes from image files only. For a printed code in front of you, the camera app on most phones scans it directly.

Which image formats work?

JPG, PNG and WebP, and any other format your browser can display. The file can be up to 15 MB. A PDF is not an image, so take a screenshot of the page that has the code.

Why does the tool say there is no readable code?

The usual reasons are blur, a code that is too small in the frame, poor contrast or a steep angle. Crop closer to the code and try again, or use a sharper copy of the picture.

Can it read a UPI QR code from a screenshot?

Yes. It shows the UPI ID, the payee name and any amount or note stored in the code. It does not start a payment. To pay, use your UPI app, most of which can also load a code from the gallery.

How do I keep track of payments received through a shop QR?

A printed code does not record anything by itself. Match each receipt in your bank or UPI app with the bill. LocalPOS billing software lets you mark the payment mode on every bill so the totals are easy to compare.
